# From Guadeloupe to Mountain View: The 10x Stargardt Warrior Journey

> "I only see through one eye due to Stargardt disease, but with code, first principles, and Gemini, I see clearer and further than ever."

---

## 1. The Genesis: Guadeloupe Without Wi-Fi
Growing up in Guadeloupe with dial-up or no Wi-Fi at all was not a disadvantage—it was the forge of autonomy. When connectivity is sparse, you cannot rely on Stack Overflow in real time. You read the source code. You read the manual pages. You compile from scratch.

At 14, while other teenagers were consuming games, I was compiling **Chromium OS** and **AOSP (Android Open Source Project)** in my bedroom on an old Microsoft Surface Book to install Android-x86. Seeing a custom-compiled kernel boot on unsupported hardware sparked an obsession that never left: systems programming, operating system kernels, compilers, and browser architectures.

---

## 2. The Medical Reality: Stargardt Disease & Monocular Vision
At an early age, I was diagnosed with **Stargardt Disease** (juvenile macular dystrophy, progressive central vision loss similar to macular degeneration). Today, I navigate the world and engineering using only one functioning eye with restricted central resolution.

In conventional environments, visual impairment is treated as a limitation. In systems engineering, it forced me to build:
- Uncompromising keyboard-driven workflows (Vim/Kakoune motions, TUI dashboards).
- Extreme high-contrast typography (Google Material You 3 high-contrast dynamic palettes, HCT CAM16 colour models).
- Audio and vision assistive co-pilots using Gemini Multimodal Live, converting visual interfaces into structured audio descriptions.

I do not want sympathy; I want to engineer the very technologies—Google Glass successors, Pixel Buds real-time scene transcribers, tactile wristbands—that restore sensory immersion for millions.

---

## 3. The Dream: Googleplex Mountain View & Google Cloud Paris
My north star has been constant for a decade:
1. **Google Cloud Paris (Rue de Londres / Vélizy)**: Bringing sovereign European cloud computing, 10x systems architectures, and extreme serverless scalability to enterprise workloads.
2. **Googleplex (Mountain View, California)**: Walking into Building 43, testing Google Glass and Project Astra assistive headsets, and working directly on core systems (Chromium, AOSP, gVisor, V8, WebGPU).

---

## 4. The Engineering Stack: Sovereign & Uncompromising
- **Runtimes**: 100% Upstream Bun v1.4.4+, Rust 2024, Go, Modern C++ (Abseil/Chromium).
- **Cloud**: Google Cloud Platform (europe-west9, Cloud Run, Cloud Spanner, Vertex AI, GKE Anthos, BigQuery).
- **Philosophy**: Larry Page 10x Rule. "Incremental improvements lead to failure over time. A 10x improvement forces you to rethink the entire problem from first principles."
